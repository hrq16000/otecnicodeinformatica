### 1. Resposta curta

### 2. O que é informática básica?
Explicação completa: conjunto de conhecimentos essenciais para usar computadores e ferramentas digitais no dia a dia.

### 3. O que se aprende em informática básica?
Lista detalhada:
- Uso do computador (ligar, desligar, reiniciar)
- Sistema operacional (Windows, conceitos de interface)
- Navegação na internet
- E-mail
- Editor de texto
- Planilhas (conceitos iniciais)
- Gerenciamento de arquivos e pastas
- Segurança básica (antivírus, senhas, golpes)
- Noções de hardware (teclado, mouse, monitor)
- Impressão

### 4. Informática básica para concurso
Tópicos que costumam cair:

- Internet e redes
- Segurança da informação
- Backup
- Noções de banco de dados

### 5. Informática básica para trabalho
Competências esperadas no mercado: digitação, e-mail corporativo, planilhas, organização de arquivos, videoconferência.
