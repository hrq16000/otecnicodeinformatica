## Estrutura sugerida

### 1. Resposta curta
Aprender informática exige prática, roteiro e paciência. Aqui vai um guia passo a passo.

### 2. Antes de começar: defina seu objetivo
- Uso pessoal
- Trabalho/escritório
- Concurso público
- Profissionalização (TI, programação, redes)

### 3. Roteiro de aprendizado em 4 fases

#### Fase 1 — Familiarização (1-2 semanas)
- Hardware básico
- Ligar/desligar
- Mouse, teclado, monitor
- Interface do Windows
- Criar pastas e salvar arquivos

#### Fase 2 — Produtividade (2-4 semanas)
- Navegador e internet
- E-mail
- Editor de texto
- Planilhas básicas
- Segurança digital

#### Fase 3 — Aprofundamento (1-3 meses)
- Sistema operacional a fundo
- Redes e Wi-Fi
- Backup
- Manutenção básica
- Resolução de problemas simples

#### Fase 4 — Especialização (contínuo)
- Escolha uma trilha: programação, redes, segurança, banco de dados, suporte técnico.

### 4. Recursos para aprender de graça
- Microsoft Learn
- Google Digital Garage
- Fundação Bradesco
- Curso em Vídeo
- LibreOffice Documentation
- Khan Academy

### 5. Informática para crianças
- Jogos educativos
- Plataformas: Scratch, Code.org
- Ensino gradual e lúdico

### 6. Informática para idosos
- Ritmo mais lento
- Repetição
- Foco no essencial: e-mail, WhatsApp Web, videochamada, segurança

### 7. Informática para concurso
- Pegue o edital
- Foque nos tópicos cobrados
- Resolva questões anteriores
- Use simulados

### 8. Erros comuns de quem estuda sozinho
- Pular a base teórica
- Não praticar
- Fazer apenas videoaulas passivas
- Não revisar

- Preciso de computador potente para começar?
- Inglês é obrigatório?
- Curso online vale a pena?
- Qual a diferença entre informática e programação?
